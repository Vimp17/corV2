## Проверенная исходная точка

Материалы: `/home/matthew/co2-model-review-2026-11-10` — REPORT.md, аудит, JSON расчётных строк и ячеек книги. Исходного генератора v4 в папке нет.

Независимый пересчёт базовой формулы из calculation_rows.json совпал с 692 из 692 сохранённых центральных значений с относительным допуском 1e-10:

`V = 10^(5.8 − 1710/(T_C + 273.15) + 0.67 × log10(pCO2_bar))`, результат — мм/год.

Это подтверждает воспроизводимость сохранённых чисел, а не полевую точность модели. По предоставленному аудиту у A1 расходится знак поправки скорости между описанием и результатом; полный A2 с HCO₃⁻ независимо не воспроизводится для 386 строк из-за неполной спецификации химического расчёта.

В corV2 поле model_math — вероятность отказа 0–1, влияющая на индекс и мероприятия. CO₂-модель выдаёт скорость мм/год и требует отдельного результата. Общий распознаватель заголовков принимает S_CO2_* за co2_pct; существующий диапазон измеренной скорости до 1,5 мм/год не подходит для всех результатов v4. Текущая readiness рейтинга требует историю наблюдений, тогда как физический сценарный расчёт использует один срез.

## Рекомендуемая первая версия

Добавить блок «CO₂-коррозия» с двумя режимами:

1. Новый расчёт воспроизводимой базовой формулы: температура, абсолютное давление, измеренная доля CO₂ или три явных сценария v4 — 0,5%, 1,5%, 3%. Сохранять входы, версию, результаты и ограничения.
2. Импорт результатов v4: сохранённые базовые/A1/A2 скорости, баллы, исходные данные и флаги качества. A1/A2 показывать как результаты внешнего расчёта, без кнопки пересчёта до согласования полной спецификации.

Карточка скважины показывает все сценарии, единицы, происхождение, даты, подстановки и статус синтетики. Центральный сценарий не называть наиболее вероятным прогнозом. При неизвестной дате состояния хранить пустую дату, отдельно от времени импорта.

Существующие рейтинг, прогноз вероятности отказа и мероприятия сохраняются. Новая скорость используется как дополнительный контекст инженеру и ИИ-агенту. Связь с индексом, вероятностью отказа и остаточным ресурсом — отдельный последующий этап после выбора методики и валидации.

## Контракт и хранение

Для нового базового расчёта: temperature_c, pressure_abs_bar, co2_mole_fraction либо набор сценариев. API использует долю 0–1, интерфейс явно преобразует проценты. Отдельный режим ввода pCO2_bar допустим с указанием происхождения. Неизвестный тип давления не превращать автоматически в подтверждённое абсолютное давление.

Импорт сохраняет pH, HCO₃⁻, расход, диаметр, скорость потока и допущения, не приписывая их базовой формуле. Не считать номинальный диаметр внутренним без подтверждения.

Новая таблица co2_assessments: ID, well_id, equipment_id при наличии, state_at, calculated_at/imported_at, model_version, calculation_mode, input_hash, source_hash, source_row, inputs, assumptions, scenario_results, imported_results, quality_flags, applicability_status, synthetic. Поисковые поля — столбцы; подробности — JSON. Повтор идентифицировать по источнику/строке и версии либо нормализованным входам и версии в зависимости от режима.

Расчётные скорости не записывать в существующее поле измерений corrosion_rate_mm_year и не обрезать до 1,5. Сохранять значение с флагом применимости. Область применения формулы фиксировать отдельно; не выводить её границы из диапазона синтетического набора.

Предлагаемые маршруты:

- POST /api/v1/co2/calculate — рассчитать и сохранить сценарии.
- POST /api/v1/co2/import — проверить файл и импортировать с отчётом.
- GET /api/v1/co2/wells/{well_id} — последний результат и история.

Использовать существующий API-ключ. Импорт показывает формат, число строк, синтетику, неизвестные ID и проблемы. Новые демоскважины создавать явно, не объединять по неявному совпадению номера.

ИИ получает структурированные значения, единицы и качество, объясняет результат и предлагает уточнить входы. Коэффициенты и недостающую химию он не генерирует. Скорость не описывать как вероятность отказа или срок разрушения. Сортировка по скорости CO₂ не меняет действующий рейтинг.

## Проверки и критерии готовности

- Базовая формула воспроизводит 692 центральных результата; три сценария соответствуют своим входным долям.
- Проверены проценты/доли, парциальное/общее давление, пропуски, нечисловые и бесконечные значения, T ≤ −273,15 °C, неположительное давление, границы долей. Нулевая доля обрабатывается явно по контракту без ошибки логарифма.
- S_CO2_* не превращается в co2_pct; импорт не создаёт вымышленные даты и историю; A1/A2 не пересчитываются незаметно.
- Повторный расчёт воспроизводим, повтор импорта не дублирует записи, ошибочные строки имеют понятный отчёт.
- На отдельной тестовой SQL Server проверены расширение схемы, чтение/запись, история и сохранность старых данных.
- Пройдены имеющиеся тесты, проверки API и визуальная проверка интерфейса. При выключенной функции прежние сценарии продолжают работать.
- Архив содержит необходимые модули и конфигурацию, без секретов; SHA-256 и BUILD_INFO проверены. Переносной runtime проверен на Windows. Непройденные проверки перечислены явно.
