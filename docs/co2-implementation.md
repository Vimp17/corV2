# CO₂-модель: реализация и проверка

Объём согласован 11.11.2026. Изменения подготовлены в рабочем каталоге; все 94 теста с SQL Server прошли; публикация и сборки требуют доступа инструментов.

## Что добавлено

- Отдельный сценарный расчёт `co2-v4-base-1`: температура, абсолютное давление, мольные доли CO₂; результат в мм/год.
- Строгий импорт JSON/XLSX v4 с предварительной проверкой, явным подтверждением новых скважин и сохранением внешних A1/A2 без пересчёта.
- Таблица SQL Server `co2_assessments`, история и идемпотентность, сохранение источника, хеша и номера строки. Неизвестные даты состояния остаются пустыми.
- API расчёта/импорта/истории с существующим ключом доступа, флаг MAI_CO2_ENABLED.
- Раздел дашборда, блок в карточке, колонки Excel и контекст ИИ-агента с ограничениями модели.
- Защита от ошибочного распознавания S_CO2_* как содержания газа.
- Автотесты, учебный пример, инструкция обновления/отката и workflow тестов/сборки/Windows smoke.

Существующие индекс и мероприятия не используют новую скорость. Полный пользовательский набор не включён в Git/поставку.

## Подтверждённые проверки

- Изолированная функция rate() из нового модуля воспроизвела 692/692 центральных базовых результатов локального набора с rel_tol=1e-10.
- Пользователь выполнил итоговый `sh scripts/test_co2_local.sh`: **94 passed, 1 warning in 104.60s**. Предупреждение — StarletteDeprecationWarning о будущем переходе тестового клиента с httpx на httpx2.
- Проверены SQL-хранение и история CO₂, идемпотентность, API-ключ, флаг отключения, экспорт, контекст агента и неизменность индекса/мероприятия.
- Все Python-файлы app/scripts/tests разобраны AST; JavaScript дашборда проверен node --check; shell-скрипт проверен sh -n; git diff --check прошёл.

## Завершение проверки

1. Выполнено: `sh scripts/test_co2_local.sh` — итоговый pytest с временной SQL Server. По умолчанию corv2-test-mssql:latest; для другого заранее подготовленного образа задайте MAI_TEST_IMAGE. Обычный corv2-test не содержит SQL-драйверов.
2. Через Python 3.12 с зависимостями выполнить `python scripts/verify_co2_dataset.py <путь-к-calculation_rows.json>` — проверка полного локального набора через модуль и импортёр.
3. Проверить формы, импорт учебного JSON и карточку на работающем стенде.
4. Зафиксировать согласованные исходники отдельным коммитом, не добавляя docker-compose.override.yml и полный набор данных.
5. `standalone/build/build.sh`, затем `python scripts/check_demo_archive.py` в подготовленном окружении.
6. Отправить ветку codex/co2-model-demo в GitHub; дождаться workflow Test and build Windows demo, включая Windows smoke. Сверить коммит в BUILD_INFO обеих поставок.

Не выдавать статическую проверку за интеграционные тесты либо готовую Windows-сборку. Для A1/A2 остаются ограничения исходной методики; полный пересчёт A2 требует генератора или спецификации химических поправок.
