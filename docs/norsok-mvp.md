# Расчёт CO₂-коррозии в MVP

Основная методика — табличная точечная модель **NORSOK M-506 Rev. 2, June 2005**: уравнения 1–8, таблицы 1–3. Это расчёт общей скорости CO₂-коррозии углеродистой стали при смачивании водой. Он не определяет остаточный ресурс, вероятность отказа, локальную коррозию или эффект ингибитора/гликоля. Редакция 2017 и полная Excel-программа NORSOK не реализованы.

## Автоматический результат в карточке

По согласованию 16.11.2026 карточка скважины сразу показывает готовый результат. Кнопка расчёта и редактирование параметров в карточке отсутствуют. При загрузке карточки, рейтинга, Excel-экспорта и контекста ИИ сервер заново считает NORSOK по актуальным источникам и текущим администраторским настройкам. Обновление данных источника автоматически отражается в следующем ответе API; отдельный запуск инженером не нужен.

Порядок: последние пригодные значения каждого параметра из телеметрии/проб и дополнительных показателей карточки, паспорта и реестра НКТ; при отсутствии — согласованная подстановка из `config/co2_defaults.json`. Показатели разных дат объединяются с сохранением источника и даты каждого поля. Нулевая обводнённость не считается пропуском. По умолчанию значения старше 30 дней и слишком далеко из будущего не применяются; причина подстановки видна в карточке. Устьевая температура из реестра используется как температура точки расчёта; пластовая температура не подменяет её.

| Администраторская подстановка | Начальное значение | Переопределение в .env |
| --- | --- | --- |
| Температура | 60 °C | MAI_CO2_DEFAULT_TEMPERATURE_C |
| Абсолютное давление | 50 бар | MAI_CO2_DEFAULT_PRESSURE_ABS_BAR |
| CO₂ | 1,5 % мол. | MAI_CO2_DEFAULT_CO2_PCT |
| pH при рабочих условиях | 5 | MAI_CO2_DEFAULT_PH_IN_SITU |
| Касательное напряжение | 19 Па | MAI_CO2_DEFAULT_WALL_SHEAR_PA |
| Обводнённость | 80 % | MAI_CO2_DEFAULT_WATER_CUT_PCT |
| Материал | carbon_steel | MAI_CO2_DEFAULT_MATERIAL |
| Контакт воды с металлом | water_wet (допущение) | MAI_CO2_DEFAULT_WATER_WETTING |

Это утверждённые стартовые **проектные допущения**, а не значения, предписанные NORSOK. В раскрывающемся блоке карточки отображаются использованные значения, их источник и результат; пояснения и технические сведения доступны через API. Материал и смачивание при отсутствии подтверждения также отмечаются допущениями. Неизвестные H₂S и кислоты по умолчанию остаются неизвестными. При необходимости администратор задаёт `MAI_CO2_DEFAULT_H2S_PARTIAL_BAR` и `MAI_CO2_DEFAULT_ORGANIC_ACIDS_PPM`.

Изменения доступны только через серверные файлы/окружение, без пользовательского API записи. `MAI_CO2_DEFAULTS_PATH` меняет путь файла, значения `MAI_CO2_DEFAULT_*` имеют приоритет над ним. Изменение JSON учитывается при следующем запросе; после изменения .env перезапустите приложение. Меняйте revision для управляемого учёта настроек. Каждому текущему результату сопутствуют снимки формулы/подстановок и их хеши. Некорректные настройки дают явный статус `configuration_error`, сохраняя доступность остальных данных карточки.

Другие настройки: `MAI_CO2_MAX_AGE_DAYS=30`; `MAI_CO2_REGISTRY_PRESSURE_BASIS=unknown|absolute|gauge`. Давление реестра в атм по умолчанию не интерпретируется как абсолютное. Если администратор подтвердил его тип, выполняется перевод: 1 атм = 1,01325 бар, для gauge добавляется одна стандартная атмосфера. Без этого используется настроечное абсолютное давление с пояснением. pH без указания рабочих условий также не переименовывается автоматически: используется подстановка. Только администратор может явно включить `MAI_CO2_ALLOW_LAB_PH_AS_IN_SITU=true`; такое использование помечается дополнительным допущением.

Реальное значение вне области NORSOK не заменяется нормой ради получения числа: возвращается `not_applicable` с причиной. Устаревшая ручная оценка не выдаётся за текущую автоматическую. Просмотр не пишет дубликаты истории и не создаёт скважины; сохранённые ручные/импортированные результаты остаются отдельной историей. Источники читаются пакетно (три SQL-запроса на 1000 скважин), с тем же объединением данных, что у карточки. Автоматическая скорость не записывается в измеренную телеметрию и не меняет индекс рейтинга.

В дашборде CO₂ представлен только раскрывающимся блоком карточки скважины, по образцу НТЦ и математической модели. Отдельного раздела, загрузки файлов и ручного калькулятора нет. Строгий ручной/файловый расчёт сохранён в API; далее описаны его входы.

## Исходные параметры

| Поле JSON / колонка | Единица и смысл | Обязательно |
| --- | --- | --- |
| well_id / Скважина | Текстовый ID; ведущие нули хранить как текст | Да |
| temperature_c / Температура, °C | Рабочая температура 5–150 °C | Да |
| pressure_abs_bar / Абсолютное давление, бар | **Абсолютное**, 1–1000 бар; избыточное давление и атм не пересчитываются автоматически | Да |
| co2_pct / CO₂, % мол. | Измеренный газовый состав в молярных процентах | Да, либо co2_mole_fraction |
| co2_mole_fraction / Доля CO₂, моль/моль | Альтернатива процентам; 0,01 означает 1 %. Обе колонки вместе запрещены | Альтернатива |
| ph_in_situ / pH при рабочих условиях | pH водной фазы при рабочих T/P, 3,5–6,5 | Да |
| wall_shear_pa / Касательное напряжение, Па | На стенке, 1–150 Па; из измерений или проверенного гидравлического расчёта | Да |
| material / Материал | carbon_steel или «углеродистая сталь» | Да |
| water_wetting / Контакт воды с металлом | water_wet или «подтверждён» | Да |
| water_cut_pct / Обводнённость, % | 0–100 %, характеристика среды | Нет |
| h2s_partial_bar / Парциальное давление H₂S, бар | Неизвестное — пусто, подтверждённое отсутствие — 0 | Нет |
| organic_acids_ppm / Органические кислоты, ppm | Аналогично: неизвестное не означает 0 | Нет |
| state_at / Дата состояния | ISO 8601 либо Excel-дата; без зоны — MAI_SOURCE_TIMEZONE | Нет |
| source / Источник | Проба/протокол; иначе сохраняется имя файла | Нет |

Расход, диаметр, минерализация и HCO₃ не заменяют непосредственно pH и касательное напряжение. Вспомогательные химический и многофазный гидравлический решатели сюда не входят. Лабораторный pH при атмосферных условиях нельзя автоматически считать рабочим. Линейный множитель по обводнённости не вводится: она не устанавливает смачивание стенки и не описывает многофазное течение. В строгом ручном/файловом расчёте значения pH/напряжения и газового состава не подставляются; автоматическая карточка использует описанную выше администраторскую политику.

При фугитивности вне 0,1–10 бар расчёт отклоняется, включая нулевой CO₂. pCO₂ должен быть меньше полного давления. При P >250 бар коэффициент фугитивности рассчитывается с P=250 по уравнению 8. Между температурными узлами линейно интерполируются **скорости**, а не коэффициенты. В точке границы кусочной функции pH выбирается правая ветвь; конечная граница 6,5 включена.

Дополнительная политика MVP консервативнее редакции 2005: блокируются pH₂S >0,05 бар, отношение pCO₂/pH₂S <20 и кислоты >100 ppm при pCO₂ <0,5 бар. Эти ограничения опираются на более поздние сведения редакции 2017 и не означают её реализацию. При неизвестной химии результат содержит предупреждение. Около 90 °C также требуется инженерная проверка.

## Загрузка и проверка

Файловый расчёт доступен через API `/api/v1/co2/calculate-file`, без формы в дашборде. CSV-шаблон выдаёт `/api/v1/co2/input-template`; поддерживаются XLSX/CSV/JSON. Проверка и подтверждение выполняются отдельными запросами. При ошибке строки файл целиком не записывается. Создание новых ID требует create_wells=true. Сохранённые оценки и их технические сведения остаются доступными через API истории.

API с обычным ключом доступа:

- `GET /api/v1/co2/model` — активная конфигурация: версия, область, хеш, калибровка.
- `GET /api/v1/co2/input-template` — пустой CSV-шаблон.
- `POST /api/v1/co2/calculate` — JSON ручного расчёта; состав — обязательный массив `co2_mole_fractions`, методика по умолчанию `active`.
- `POST /api/v1/co2/calculate-file` — multipart `file`, `synthetic`, сначала `confirm=false`. Для записи — `confirm=true`, полученный `configuration_hash` и при необходимости `create_wells=true`. Изменившаяся конфигурация требует повторной проверки.
- `GET /api/v1/co2/wells/{well_id}` — история.
- `POST /api/v1/co2/import` — сохранённые внешние результаты v4, без пересчёта в NORSOK.

Сравнительная базовая формула остаётся доступной через явный `model_id="co2-v4-base-1"`. Она не учитывает pH и поток. Старые записи и внешние A1/A2 не перезаписываются.

## Корректировка и замена

`config/co2_model.json` содержит температурные узлы, коэффициенты pH/фугитивности/сдвига, области и `rate_multiplier`. Другой путь задаётся `MAI_CO2_MODEL_PATH`. Для калибровки измените файл, укажите новую `revision`, выполните контрольные тесты и загрузите свои контрольные точки. Коэффициенты перечитываются для каждого запроса; для смены переменной окружения нужен перезапуск. Весь пакет файла читается один раз на загрузку. Настройка хранится у администратора, API редактирования коэффициентов отсутствует.

Любое изменение конфигурации меняет хеш и идентичность новых результатов. Полная копия конфигурации остаётся в истории каждого расчёта. Ошибочная конфигурация даёт 503 и не заменяется базовой формулой. Версия с хешем ограничена 64 символами по существующей схеме БД.

Численное ядро `app/core/norsok.py` не зависит от SQL/ИИ/HTTP. Контракт результата собирается в `app/core/co2_corrosion.py`, файлы читает `app/core/co2_inputs.py`, запись выполняет `app/db/co2.py`. Для другой физической формулы добавляется отдельная чистая функция и явный идентификатор/валидатор конфигурации с адаптером в `co2_corrosion.calculate`; файловый импорт, история, UI и SQL-контракт сохраняются. Произвольные выражения и исполняемые плагины из JSON не загружаются.

## Проверка и источники

Тесты численных точек и файловых/интерфейсных контрактов добавлены и запущены **до** соответствующей реализации. Проверяются табличные значения, интерполяция, pH/сдвиг, фугитивность, единицы, неполные данные, область применения, конфигурация, атомарность и повторная запись. Интеграционный набор запускается `sh scripts/test_co2_local.sh`; второй драйвер — `MAI_TEST_SQL_DRIVER=pyodbc`. Браузерная приёмка — `python scripts/browser_smoke.py` с отдельной mai_test БД. GitHub проверяет оба драйвера и переносимый Python на Windows.

Таблицы и уравнения сверены по полному документу M-506:2005, включая изображение таблицы pH. Контрольные точки — независимые численные примеры; исходный набор 692 сохранённых результатов v4 не является эталоном NORSOK. Исходный PDF (SHA-256 `46d4c7e950303e4d099fac5d06b29c3f2af30a1796ff0fbe19fa453aa374f9d2`) и приватные наборы не включены в репозиторий/поставку. Официальная страница дополнительных материалов: https://standard.no/tilleggsdokumenter . Публичный предварительный текст M-506:2017: https://avadocuments2026.com/preview/norsok-m-506-2017.pdf .

Для производственного применения остаются инженерная валидация на реальных измерениях и проверка соответствия выбранной редакции стандарта. Наличие работающего калькулятора само по себе их не заменяет.
