Формат .xlsx, до 15 МБ

Обязательно: дата/время и ID скважины (в таблице или в поле выше). В каждой строке телеметрии нужен минимум один показатель. Для расчёта по умолчанию нужно 8 разных дат, 8 записей за последние 28 дней, 2 актуальных показателя за 7 дней и данные не старше 48 часов. Источник можно разбить на несколько листов с одной структурой колонок. Файл с несколькими скважинами загружайте без общего ID; ниже выберите нужную скважину.

Формат .json

Файл должен содержать массив бригад или объект {"crew_availability": [...]}. Обязательные поля записи: crew_id, specialties, region, status (available / busy / unknown), available_from и available_to в формате ISO 8601. Если галочка снята, укажите ID скважины.
