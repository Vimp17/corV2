Документы

Акты демонтажа и разбора, протоколы хим. анализа, паспорта скважин, реестр коррозии НКТ — PDF, сканы, фото и Excel. Система распознаёт текст (сканы — OCR-моделью), определяет тип и извлекает данные с цитатой из документа. Подтверждённые данные попадают в рейтинг; нераспознанный документ не учитывается — данных по нему нет.

Загрузка данных

Одна карточка на источник из config/source_profiles.json. После загрузки рейтинг пересчитывается для скважин из файла. Если у источника настроен API, дневной цикл запрашивает данные сам.
Загружаем список источников…
Рейтинг рассчитывается системой по данным ДАРС, ХИМИК и ЭРА ремонта: из API источников, если они настроены, иначе по загруженным файлам. Пороги и сроки — переменные MAI_RATING_*. Рекомендации требуют проверки инженером; предложения по ЭРА ремонта уходят в Промайн только после нажатия «Отправить».
